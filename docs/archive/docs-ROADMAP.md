# Roadmap

## v1.0.0 — Current Release

- Multi-provider AI chat (OpenAI, Anthropic, Gemini, Ollama)
- Streaming responses with stop/cancel
- Auto-routing for provider selection
- Workspace intelligence (languages, frameworks, configs, git, README)
- Project Brain (manual entries)
- Memory system (global + workspace, search, auto-extraction)
- Prompt library (categories, variables)
- Global search (chats, messages, prompts, memories, settings)
- Command palette (Ctrl+K)
- Usage analytics (tokens, costs, per-provider)
- Terminal integration (approval checkpoints)
- Git status/commit/diff
- File tools (PDF, image, OCR, JSON)
- Custom titlebar, splash screen, onboarding
- SQLite with WAL + auto-backup
- Windows packaging (NSIS + portable)
