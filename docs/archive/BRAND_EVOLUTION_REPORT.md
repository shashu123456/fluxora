# FLUX VORTEX — Brand Evolution Report

Evolves the FLUX ORBIT identity into a **four-blade vortex with a floating intelligence core**.
Family signature is preserved (four blades, central orb, rotational energy) — the original family
is not replaced, only perfected per the evolution brief.

## 1. What changed

| Surface | Before (FLUX ORBIT) | After (FLUX VORTEX) |
| --- | --- | --- |
| Mark geometry | tilted ribbon band + echo arc + trailing node | four tapered liquid-titanium blades, champagne-gold floating orb, asymmetric balance |
| Blade shape | constant-thickness stroke band | tapered blades — thick at hub, ground to razor points at the apex |
| Central orb | small node dot | floating optical-sapphire orb with bright hot core + dark rim ring |
| Materials | flat blue→violet→cyan gradient | Black Obsidian + Champagne Gold, Matte Titanium, Electric Sapphire accents |
| App icon (ico/png) | v1 PNGs | 1:1 redesigned `build/icon.png`, `build/icon.ico` (16–1024 px, shortcut/taskbar/installer) |
| Favicon | v1 inline ring data-URI | v2 vortex glyph data-URI (`index.html`, verified in `dist/`) |
| In-app mark | hand-coded `BAND_PTS`/`ECHO_PTS` polylines | bundled SVG asset — single source of truth, always matches the icon |
| Chat empty state | plain Bot tile | obsidian vortex watermark + gradient chip |
